# ShopEase — Task 5 Capstone

## Full-Stack Deployment & Project Architecture

Features:
- Modular frontend using ES modules
- Client-side routing
- Product search and category filter
- Product details
- Shopping cart with LocalStorage
- Responsive mobile-first UI
- Dark mode
- Lazy-loaded images
- Semantic/accessibility-friendly markup
- Vercel/Netlify deployment ready

Routes: `#/`, `#/products`, `#/product/1`, `#/cart`, `#/about`, `#/contact`

## Deployment
Push this folder to GitHub, then import the repository into Vercel or Netlify. It is a static project, so no build command is required.

## Submission
Submit the deployed public URL and GitHub repository URL if your training portal asks for both.

Note: Checkout is a demo. Real payment processing requires a secure backend and payment provider.
